Cómo obtener el ID de cliente

  1. Entra en console.cloud.google.com y crea o elige un proyecto.
  2. Ve a API y servicios → Pantalla de consentimiento de OAuth. Elige Interna si el proyecto pertenece a la organización de ulasalle.edu.pe; si no, elige Externa y añade tus cuentas de prueba.
  3. En Credenciales → Crear credenciales → ID de cliente de OAuth, tipo Aplicación web.
  4. En Orígenes de JavaScript autorizados añade exactamente http://localhost:8000. Debe coincidir carácter a carácter, puerto incluido. No hace falta URI de redirección.
  5. Copia el ID de cliente (termina en .apps.googleusercontent.com).

Dónde ponerlo

  1. Abre el archivo .env en la raíz del repositorio (cópialo de .env.example si aún no existe).
  2. Rellena la línea GOOGLE_CLIENT_ID=… con el valor que copiaste.
  3. Arranca el servidor con python3 servir.py y recarga esta página.
