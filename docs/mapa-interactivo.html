Pulsa un botón y lee, de arriba abajo, qué código se ejecuta

La app tiene tres piezas. Cada botón empieza en la pantalla, casi siempre viaja al servidor, y el servidor lee o escribe en el Google Sheet. Después la respuesta vuelve a la pantalla. Este mapa muestra ese viaje con el código real del proyecto.

04
Versiones y bloqueos

  
Cuatro reglas explican todo. Abajo puedes probarlas con dos coordinadores de la misma carrera.

  

    
1 · Guardar agrega una filaCada «Guardar» escribe una fila nueva en Planes (o Cargas) con el contenido completo. Nunca se edita ni se borra una versión.

    
2 · La vigente es la más altaNo hay una columna «actual»: la versión vigente de una carrera es la de número más alto en ese ciclo.

    
3 · Editar escribe un bloqueoAl pulsar «Editar» se escribe tu fila en Bloqueos con vencimiento a 30 minutos. Mientras siga vigente, los demás solo pueden ver.

    
4 · Guardar exige tu bloqueo y tu versiónSolo se guarda si tu bloqueo sigue vigente y nadie guardó otra versión desde que abriste. Guardar y Salir borran el bloqueo.

  

  

    

    
Pulsa «Ana · Editar» para empezar.

06
Publicar cambios

  
Un cambio de código pasa por cuatro sitios. El Google Sheet no cambia: es siempre el mismo y la app lo encuentra sola porque el proyecto está pegado a él.

  

    
GitHub
El cambio se guarda en Git (rama, PR, merge a main).
git checkout main && git pull

    
Proyecto de Apps Script
clasp push copia AppScript/ al proyecto (sin pruebas/, por .claspignore).
cd AppScript && clasp push --force

    
Prueba en /dev
La URL que termina en /dev usa lo último que subiste. Ojo: escribe en el Sheet de verdad. Está en Apps Script → Implementar → Probar implementaciones, o en la línea @HEAD de:
clasp list-deployments

    
Publicar en /exec
La URL pública /exec sigue con la versión anterior hasta que la actualizas (solo cuando lo pida el equipo):
clasp deploy -i AKfycbw7tEwKcnD54HU4To7xEiKA0FHBecpk3e_MAgdoFc81_55fWWG-NcsfmPSAq0BpkKZB -d "…"

  

  
▦ Abrir el Google Sheet Su ID también está en AppScript/.clasp.json (parentId). Desde el Sheet: Extensiones → Apps Script.
