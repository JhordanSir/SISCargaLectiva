El sistema todavía no está instalado

Faltan la carpeta de Drive y la hoja de cálculo del sistema. La cuenta propietaria del script debe instalarlas una vez.
  1. Abre el proyecto en el editor de Apps Script (clasp open-script).
  2. Elige la función instalar y pulsa Ejecutar. Acepta los permisos que pide Google.
  3. El registro de ejecución muestra el enlace de la carpeta SISCargaLectiva. Sube ahí los archivos CargaXCarrera y CargaXDepartamento (.xlsx, sin convertir).
  4. Recarga esta página.
