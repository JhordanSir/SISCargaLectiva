El sistema todavía no está instalado

El libro todavía no tiene las hojas del sistema. La cuenta propietaria del proyecto debe instalarlas una vez.
  1. Abre el proyecto vinculado al libro en el editor de Apps Script (clasp open-script).
  2. Elige la función instalar y pulsa Ejecutar. Acepta los permisos que pide Google.
  3. El registro de ejecución muestra el enlace de la carpeta SISCargaLectiva · Excel de origen. Sube ahí CargaXCarrera, CargaXDepartamento y CargaDeDocentes (.xlsx, sin convertir).
  4. Ejecuta sembrarCiclo con el ciclo que traen esos Excel y recarga esta página.

Acceso denegado

Si tienes varias cuentas de Google abiertas, cambia a tu cuenta institucional y recarga la página.
